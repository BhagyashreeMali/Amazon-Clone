## 📖 Overview

This project is a high-fidelity clone of the Amazon e-commerce platform's frontend. It was built to master the fundamentals of web design, focusing on the **CSS Box Model**, **Flexbox layouts**, and **responsive component design**. The application provides a visual experience identical to the original site, showcasing attention to detail in spacing, typography, and color schemes.

## ✨ Key Features

- **🎯 Pixel-Perfect Design**: accurate recreation of Amazon's complex UI elements.
- **📱 Responsive Navigation**: Complex navbar with flexbox alignment, search bar integration, and hover states.
- **🖼️ Hero Section**: Immersive hero banner with dynamic background positioning.
- **📦 Grid Layout System**: Product cards displayed in a responsive grid layout using CSS Flexbox (mimicking Grid behavior).
- **🎨 Modern Styling**:
  - CSS Variables (implied usage for consistent colors).
  - Hover effects on cards and buttons.
  - FontAwesome icon integration for a polished look.
- **🔗 Footer Navigation**: Multi-column footer layout with categorized links.

## 🛠 Tech Stack

| Technology | Usage |

## 🚀 Getting Started

To view this project locally, follow these simple steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/Amazon-Clone.git
   ```
2. **Navigate to the project directory**
   ```bash
   cd Amazon-Clone
   ```
3. **Open the project**
   - Simply open `index.html` in your preferred browser (Chrome, Firefox, Safari).
   - Or stick with the VS Code "Live Server" extension for the best experience.
